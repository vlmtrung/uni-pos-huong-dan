# Hướng dẫn Uni POS

Trang hướng dẫn cài đặt và sử dụng phần mềm bán hàng Uni POS (cửa hàng vật tư nông nghiệp).
Là trang web tĩnh (HTML + CSS), không cần build, không gọi dịch vụ bên ngoài.

- `index.html` trang chủ
- `cai-dat.html` hướng dẫn cài đặt
- `su-dung.html` hướng dẫn sử dụng
- `assets/` CSS, font Be Vietnam Pro (SIL Open Font License 1.1) và ảnh chụp màn hình (dữ liệu mẫu, không phải dữ liệu thật)

Xem tại GitHub Pages của repo này.
